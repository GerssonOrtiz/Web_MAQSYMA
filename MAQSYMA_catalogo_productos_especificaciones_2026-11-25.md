# 14. Observaciones comerciales para MAQSYMA

### 14.1 El catálogo tiene una fuerte concentración en ESAB

La tienda muestra ESAB como la marca dominante. Esto permite estructurar la web alrededor de:

**ESAB → proceso → aplicación → equipo recomendado → cotización.**

### 14.2 Hay una diferencia importante entre productos con precio y productos “a cotizar”

Los modelos pequeños y algunos equipos profesionales tienen precio público, mientras que una parte importante del catálogo industrial aparece sin precio.

Esto puede aprovecharse para separar:

- **Compra directa:** precio visible + CTA comprar.
- **Equipo profesional:** precio + CTA consultar.
- **Equipo industrial:** “Solicitar cotización”.
- **Alquiler:** CTA específico para alquiler.

### 14.3 El catálogo tiene información suficiente para crear un buscador técnico

Los filtros públicos incluyen:

- Corriente máxima
- Proceso
- Tamaño/tipo
- Tensión de entrada
- Categoría
- Marca

Esto permitiría construir un **“Encuentra tu máquina”** en la web.

Ejemplo:

> ¿Qué necesitas soldar?
>
> 1. Tipo de proceso
> 2. Espesor del material
> 3. Trabajo ocasional / profesional / industrial
> 4. Alimentación disponible
> 5. Corriente requerida
>
> → MAQSYMA recomienda 2–3 equipos.
